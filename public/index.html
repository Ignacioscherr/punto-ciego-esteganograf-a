Modo de Uso

1. Para Ocultar: Selecciona o arrastra una imagen, escribe el mensaje que quieras guardar y define una contraseña. Al presionar Ocultar, se descargará una nueva imagen PNG que parece idéntica pero contiene tu mensaje cifrado adentro.

2. Para Revelar: Carga la imagen descargada, escribe la misma contraseña y presiona Revelar para recuperar el texto original en cualquier momento.
